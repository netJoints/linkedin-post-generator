A writing desk on your laptop

LinkedIn drafts,
written on this machine

Give it a company, topics, optional instructions, up to five links, and one file. A local model writes a longer article and a shorter post. You paste them into LinkedIn yourself.

Open with the boundary: the model runs on the laptop. The app does not log in to LinkedIn and does not post.

Two outputs: a longer article and a shorter feed post. Both are plain text you copy or download.

The form

Topics are required. Instructions steer the draft.

Company

Optional. Example: Cisco. The model may use the name. It does not invent products, announcements, or metrics unless the instructions or a source state them.

Topics

Required, and kept short. Example: AgenticOps, AI security. Up to 12. An optional instructions box says what the post should do, such as announce an event and invite people. It does not search the web.

Links

Optional. One per line, up to five. Pages are read as text. A YouTube link can include its transcript.

One file

Optional. A PDF, Word document, or .txt file, up to 8 MB. It is read in memory and not saved.

If there is no link and no file, the model writes from the topic names and any instructions. Say that out loud so people do not treat a thin draft as sourced. Instructions cannot send it to browse a website.

Two plain-text pieces

An article for the long form, and a post for the feed.

Article

The first line is the title. Then 500 to 700 words in short paragraphs. It ends with one specific question, under 18 words. Download it as linkedin-article.txt.

Short post

Up to 130 words, written as the video caption. With no instructions, the first line names the problem and it ends with one specific question. Three hashtags. No URL. Download it as linkedin-post.txt. Links you supplied are listed in a first comment.

No markdown, no HTML, no asterisks. The caption has no URL. When you supplied links, paste the first comment after you publish.

If the short post is missing, the article is still shown. A smaller model is more likely to skip the second section. Run it again.

How a draft
moves

The browser, the sources, and the model all stay on this laptop. A link or a caption is fetched from here. The writing is not sent to a cloud model.

01

Pause on the boundary before the diagram. Generation stays local. Fetching a public page or a YouTube caption does use the network, from this app.

The request

Sources come in. The model answers on localhost.

The server listens on 127.0.0.1 only. Other machines on the network cannot open it.

Each link is checked before it is opened. Only http and https. No username or password. Loopback, private, and link-local addresses are rejected.

A link can carry what was said

A YouTube video contributes its transcript when captions exist.

No captions

The draft still runs. The source list says “title only, no transcript.” A channel or playlist page is not one video.

Vimeo

Title and author only. This deck’s transcript path is for YouTube.

The watch page often has no caption text, and a direct fetch can be refused. The app asks YouTube’s player endpoint for a caption track, then downloads that track.

A caption address is opened only when the host is YouTube or Google video, after the same public-address check as any other link. No API key and no browser cookies.

Optional attachment

One file joins the links as background, then it is discarded.

What is accepted

PDF, Word .doc or .docx, or .txt. Up to 8 MB. About 8,000 characters of the text are kept. UTF-16 text is read.

How it is read

The bytes are checked against the type. The text is extracted in memory. The original file is not written to disk.

What is refused

A scanned PDF with no text layer. An encrypted PDF. A file whose bytes do not match PDF, Word, or plain text.

The model is told to use the document as background and not to contradict it. Text inside the file is reference material. It is not a set of instructions.

Before anything is opened

A link has to be a public page. A caption has to be a YouTube host.

  • Only http and https. A username or password in the link is rejected.The same check runs again if the site redirects.
  • Localhost, private, link-local, and other non-public addresses are blocked.The app does not fetch the laptop’s own network from a pasted link.
  • A YouTube caption address is opened only for YouTube or Google video.A caption file that declares a document type or an entity is not parsed.
  • Words inside a page, a transcript, or a file are reference, not orders.The model is told to leave out any claim the sources do not support.

There is still no database. Drafts are not saved on the server. Copy or download them from the page.

Do not paste customer data or other sensitive material if that conflicts with the rules of the machine you are using. The prompt stays on the laptop, and so does the model.

Choose one in the form

Pull at least one. The page disables a model that is not installed.

Mistral Small 3.2

Tag mistral-small3.2. About 15 GB. Stronger instruction following and a 128K context window. Prefer it when the laptop has 24 GB of memory.

Gemma 4 12B

Tag gemma4:12b. About 8 GB. Faster and lighter. Prefer it on a 16 GB laptop. Thinking mode is turned off so the reply is the draft.

Ollama 0.31.0 or newer. Gemma 4 12B refuses to load on older releases. The first reply after a cold start is slower because the model is loading.

start.sh checks Python, checks that Ollama is running, and checks that at least the expected model names are installed. If one is missing it prints the ollama pull command and exits.

Read the draft before you post it. The model can still be vague or wrong.

Post via Pics

Up to ten pictures become one MP4, about eight seconds each.

Pictures

Up to 10. JPEG, PNG, WebP, GIF, or SVG. Drag a row to reorder. The files are not saved.

Transitions

Crossfade, slide, wipe, push, or zoom. Each takes 0.7 seconds between two pictures.

Music

Six public-domain tracks, with Low, Medium, and High volume.

Voiceover

Your recording, a local AI voice, or My voice. The voice is trimmed to the length of the pictures.

The browser draws each picture. The server joins them with ffmpeg, and the music and voice are mixed in one pass. All of it stays on this laptop.

The post text sits on the pictures. URLs are removed so LinkedIn does not turn the post into a link preview.

Background track

Six public-domain tracks. The voice always stays on top.

  • Meditating Beat, River Meditation, Inspiration, Inventing Flight, Energizing, CelebrationPublic domain, CC0, from FreePD.com. Credit is not required.
  • Low, Medium, or High volumeMedium is the default. The track loops to the video length and fades in and out.
  • Ducked under the voiceWhile the voiceover speaks, the music drops, so the speech stays clear.
  • No YouTube, no borrowed tracksOnly music with a licence that allows reuse is bundled.

The track list and the licence notes are in static/music/CREDITS.txt. Each file is the first 100 seconds, levelled so it sits under speech.

Read the post aloud

A local AI voice reads the post. No Mac voices.

Kokoro-82M

Six voices: Heart, Bella, Nicole, and Michael in US English, Emma and George in UK English. Apache-2.0. Fast on the CPU.

Chatterbox

MIT, by Resemble AI. A default voice with a natural delivery. Slower to make. Each output carries an inaudible watermark.

Chatterbox, my voice

Chatterbox speaks with a sample of your voice. It appears after you save the sample once.

Kokoro makes a post in seconds. Chatterbox on an Apple M4 Pro took about 30 seconds for a 6-second clip, after a 9-second model load. Plan for that on a long post.

Several other voice models were reviewed and left out, because their weights are limited to research or non-commercial use.

Save once, reuse in every video

One voice sample. Re-learn it any time.

  • Choose a sample, then Save my voiceRecord 15 to 30 seconds of you reading a paragraph in a quiet room.
  • Used automatically after thatPick Chatterbox, my voice. You do not upload the sample for each video.
  • Re-learn with a better sampleSaving again replaces the old one.
  • Forget it at any timeThe file is deleted, and the option leaves the list.

This does not train a model. Chatterbox copies the voice from the saved sample on each run, so a clean sample matters more than a long one.

The sample is stored under ~/.linkedin-tts/my-voice, outside the repo. Only use a voice you have permission to copy.
